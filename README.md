Portofolio Mahasiswa Semester 3 (ITPLN)

Proyek ini adalah implementasi dasar Responsive Web Design (RWD) menggunakan HTML dan Tailwind CSS, dirancang untuk memenuhi spesifikasi tugas mata kuliah. Fokus utama adalah pada struktur yang jelas dan pemanfaatan kelas responsif dasar.

Spesifikasi Proyek

Website ini terdiri dari 3 halaman yang saling terhubung:

index.html (Beranda): Menyajikan Hero Section, Tentang Saya, dan Keahlian Dasar (HTML, CSS, JS, Tailwind).

portfolio.html (Portofolio/Data): Menampilkan tabel proyek dummy (minimal 5 data). Tabel menggunakan overflow-x-auto agar tetap responsif di perangkat mobile.

contact.html (Kontak): Berisi formulir sederhana "Request Project" dengan elemen input dasar yang responsif.

Teknologi yang Digunakan

HTML5: Struktur utama.

Tailwind CSS (CDN): Digunakan untuk styling, layout, dan implementasi RWD.

CSS Dasar: Minimal, hanya untuk impor font Inter.

Cara Penggunaan

Unduh File: Dapatkan semua file (.html dan README.md).

Ganti Placeholder: Ubah [Nama Anda] dan data dummy lainnya.

Jalankan: Buka index.html di browser Anda.
